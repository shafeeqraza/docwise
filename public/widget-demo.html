DocWise Chat Widget Demo Ready

Test the standalone embeddable chat widget with live configuration

Configuration

ℹ️ Instructions

1. Enter your API URL (e.g., http://localhost:8000)
2. Enter a valid API key from your backend
3. Customize the appearance (optional)
4. Click "Initialize Widget" to load the chat widget
5. Look for the floating chat button in the corner you selected

Embed Code

Copy this code to embed the widget on your website:

<!-- DocWise Chat Widget --> <script src="https://your-domain.com/widget.js"></script> <script> DocWiseChat.init({ apiKey: 'YOUR_API_KEY', apiUrl: 'https://your-domain.com', primaryColor: '#3B82F6', position: 'bottom-right', theme: 'light', greeting: 'Hi! How can we help you?' }); </script>

Testing Checklist

⚠️ Important Notes

• Make sure your Laravel backend is running (php artisan serve)
• Ensure CORS is configured to allow requests from this origin
• You need a valid API key from the backend (create via API or admin panel)
• Check browser console for any errors
• Session data is stored in localStorage (check Application tab in DevTools)
